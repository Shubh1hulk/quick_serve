Put a REAL 3D model of a product here to replace the photo-based spin in the hero.

Name it after the product id (see js/data.js), for example:
  p1.glb   -> boAt Rockerz 450 headphones
  p6.glb   -> Campus running shoes
  p2.glb   -> Samsung Galaxy M35
  p8.glb   -> Fastrack sunglasses
  p4.glb   -> Noise smartwatch

If the file exists, the hero loads it and the user can spin it 360 degrees. If not, the site
falls back to the photo-based 3D spin. Good free sources: Sketchfab (download as glTF/GLB),
Poly Pizza, Smithsonian 3D. Check the licence and add a credit line in the footer.
